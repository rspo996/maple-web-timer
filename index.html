메이플 재획 알리미 솔 에르다 · 부스터 · 룬

“게임 화면 연결”을 눌러 메이플스토리 창을 공유하세요.
처음 설정하는 법
  1. 게임 화면 연결 → 메이플스토리 창을 선택합니다. (이 탭은 다른 모니터에 두거나 뒤로 숨겨도 계속 동작합니다)
  2. 솔 에르다 / 부스터를 켠 상태에서 카드의 등록을 누르고, ① 버프창 전체를 드래그 → ② 해당 아이콘 하나만 꼭 맞게 드래그.
  3. 룬이 미니맵에 보일 때 룬 카드의 등록 → ① 미니맵 전체 → ② 룬 아이콘만 드래그.
  4. 지속시간 칸을 비워두면 한 번 켜졌다 꺼지는 걸 보고 자동으로 학습합니다. 알고 있으면 분:초로 직접 입력하세요.
  5. 일치도 숫자를 보면서 켜져 있을 땐 기준값보다 높고, 꺼져 있을 땐 낮게 나오도록 기준값을 조절하세요.

설정은 이 브라우저에 저장됩니다. 게임 해상도·창 크기가 바뀌면 다시 등록해야 합니다.
