게임 화면

“게임 화면 연결”을 눌러 메이플스토리 창을 공유하세요.
처음 설정하는 법
  1. 게임 화면 연결 → 메이플스토리 창을 선택합니다. (이 탭은 다른 모니터에 두거나 뒤로 숨겨도 계속 동작합니다)
  2. 솔 야누스와 부스터는 따로 등록하지 않아도 자동으로 찾습니다. 부스터는 화면 위쪽 가운데 “남은시간” 타이머의 숫자를 직접 읽어요. 잘 안 잡히면 등록으로 직접 지정하세요(부스터는 ② 단계에서 “◷ 남은시간” 글자를 드래그).
  3. 룬이 미니맵에 보일 때 룬 카드의 등록 → ① 미니맵 전체 → ② 룬 아이콘만 드래그.
  4. 다른 버프는 “+ 대상 추가”에서 이름을 고르고 영역 → 아이콘 순서로 등록하세요. 카드는 기본으로 접혀 있고 펼치기로 설정을 볼 수 있어요.
  5. 사냥 멈춤은 “+ 대상 추가 → 다른 알림”에서 만들고 경험치 막대와 숫자를 한 번에 드래그하세요. 경험치 숫자나 퍼센트가 영역에 들어가야 해요. 마을에 갈 때는 쉬기를 누르세요.
  6. 설치기 쿨타임은 “+ 대상 추가 → 다른 알림”에서 만들고, 쿨타임이 없어 밝을 때 퀵슬롯의 스킬 아이콘을 드래그하세요. 스킬을 쓴 뒤 쿨타임 중에 쿨타임 중 찍기를 누르면 더 정확해져요.
  7. 작은 창 열기를 누르면 항상 위에 뜨는 작은 창에 상태가 보이고 알림이 울리면 그 줄이 깜빡여요. 게임이 전체 화면이면 작은 창이 안 보일 수 있어요. 창 모드나 전체 창 모드를 쓰면 보여요.
  8. 지속시간 칸을 비워두면 한 번 켜졌다 꺼지는 걸 보고 자동으로 학습합니다. 알고 있으면 분:초로 직접 입력하세요.
  9. 일치도 숫자를 보면서 켜져 있을 땐 기준값보다 높고, 꺼져 있을 땐 낮게 나오도록 기준값을 조절하세요.

알림 소리는 대상마다 달라요. 각 카드의 알림 테스트로 미리 들어 보세요. 화면 연결이 끊기거나 게임 화면이 들어오지 않으면 낮은 경고음과 음성으로 알려요. 아래 알림 소리 바꾸기에서 내 WAV 파일로 바꿀 수도 있어요.

설정은 이 브라우저에 저장됩니다. 게임 해상도·창 크기가 바뀌면 다시 등록해야 합니다.
